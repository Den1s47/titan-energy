# ПАК «Титан-Энергия» (EMS) — SCADA + MES

Двухуровневая система мониторинга качества электроэнергии (по ТЗ ООО «ЭНСИТЕХ»):

- **SCADA-уровень** — сбор телеметрии 1 Гц по Modbus TCP, мнемосхема ПС 110/10 кВ
  с динамической индикацией и drill-down, телеуправление (двухшаговый алгоритм
  с блокировками), журналы ISA-18.2 с квитированием, осциллограммы при КЗ;
- **MES-уровень** — аналитика: тренды с зумом «как на бирже», карты Шухарта
  и CUSUM, гистограммы, КПЭ (доступность, аварийность), экспорт CSV/Excel.

**Модель объекта** — учебная понизительная подстанция 110/10 кВ: два ввода
110 кВ → два трансформатора (T1/T2) → две секции шин 10 кВ (по 4 фидера) →
секционный выключатель (нормально отключён). **Ключевой сценарий**: потеря
ввода 110 кВ → аларм с подсказкой оператору → переброс питания секции через
секционный QF (блокировка параллельной работы вводов) → автоматический
возврат в норму (аналог АПВ).

«Оборудование» — Modbus TCP симулятор (2 устройства, unit 1/2) со сценарным
движком: КЗ (с осциллограммой), перегрузка, перенапряжение, обрыв кабеля,
потеря ввода 110 кВ. Замена на реальное оборудование = смена конфигурации
адаптера, код выше адаптера не меняется.

## Быстрый старт (~10 минут)

### 1. Установить (один раз)
- Python 3.12+ — https://python.org
- uv: `powershell -c "irm https://astral.sh/uv/install.ps1 | iex"`
- Node.js LTS 18+ — https://nodejs.org (для сборки UI)
- PostgreSQL 16 — https://www.postgresql.org/download/windows/

### 2. База данных (один раз)
```sql
CREATE DATABASE titan ENCODING 'UTF8';
CREATE USER titan_app WITH PASSWORD '<пароль из config/.env>';
GRANT ALL PRIVILEGES ON DATABASE titan TO titan_app;
```
Таблицы создаются автоматически при первом старте. Строка подключения —
в `backend/config/.env` (вне репозитория, см. `.env.example`).

### 3. Собрать и запустить
```bash
# Бэкенд (порт 8000 + embedded Modbus-симулятор на 5020)
cd backend
uv sync
uv run uvicorn titan.api.app:app --host 127.0.0.1 --port 8000

# Фронтенд: собрать один раз (статика отдаётся FastAPI)
cd ../frontend
npm install && npm run build
```
Открыть **http://127.0.0.1:8000** — вход admin / admin (сменить пароль
в разделе «Администрирование»!).

### 4. Проверка
```bash
cd backend
uv run pytest tests/test_api.py tests/test_collector.py tests/test_factory.py tests/test_m1_db.py tests/test_simulator.py -q   # 28 passed
uv run pytest tests/test_m2_auth.py tests/test_m4_tu.py tests/test_m5_analytics.py tests/test_m6_backup.py -q                  # 31 passed
```
(Итого 59 тестов; двумя батчами — стабильнее на Windows; параллельные
прогоны pytest на одной машине не запускать.)

```

  titan/
    simulator/   — Modbus TCP «оборудование» + сценарный движок аварий
    collector/   — опрос 1 Гц, оценка качества, события ISA-18.2, архив в БД
```

## Демонстрация аварий (пульт симулятора, admin)
- **Потеря ввода 110 кВ** — плечо обесточено; переброс через секционный QF (ключевой сценарий)
- **КЗ (МТЗ)** — ток ×6, сработка защиты, отключение, осциллограмма в журнале
- **Перегрузка** — выход P и THDi за техно-границы (оранжевые плитки)
- **Перенапряжение** — U → 460 В (suspect)
- **Обрыв кабеля** — на вводе = потеря связи всего плеча

Аварии также создаются **ПКМ прямо на мнемосхеме** (роль admin).

## Безопасность
- Пароли — PBKDF2 с индивидуальной солью; сессии — JWT
- Права проверяются на сервере на КАЖДОМ эндпоинте (viewer/dispatcher/admin)
- ТУ: двухшаговый алгоритм (токен 10 с) + блокировки физики процесса
  (параллельная работа вводов, двойное обесточивание)
- Аудит: operator_actions — кто, когда, что сделал
- Пентест ×2: SQLi (параметризация), forged-токены (410), аномальные
  параметры (400/422), Infinity/NaN — отсекаются
- Секреты — в `config/.env`, вне репозитория

## Резервное копирование
```bash
cd backend
uv run python -m titan.backup_cli            # копия + ротация (хранить 7)
uv run python -m titan.backup_cli --list     # список копий
uv run python -m titan.backup_cli --restore titan_YYYYMMDD_HHMMSS.dump
```
Ночной бэкап и автозапуск — через Task Scheduler или NSSM: см. DEPLOY.md.

## Технические заметки
- **pymodbus закреплён на 3.9.2** — 3.12+ переделал API; обновление потребует
  переписать симулятор. Сервер pymodbus смещает адреса на +1 (`addr + 1`).
- PostgreSQL 16 + asyncpg (async SQLAlchemy); SQLite — только в тестах
  (`TITAN_TEST_DB=1`, временная БД на процесс, NullPool против «database is locked»).
- Время: UTC в БД, GMT+3 на бэкенде (titan/timeutil.py).
- SPA-catch-all объявлен ПОСЛЕ всех /api/* маршрутов.
- Если порт 5020/8000 занят зависшим процессом — `netstat -ano | findstr :5020`
  и taskkill по PID.
- Полный pytest одним прогоном на этой машине нестабилен (конфликт портов
  симулятора между батчами) — использовать 2 батча из раздела «Проверка».
