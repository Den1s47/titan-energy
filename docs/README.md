# ПАК «Титан-Энергия» (EMS) — MVP

Двухуровневая система мониторинга параметров качества электроэнергии (ТЗ ООО «ЭНСИТЕХ»):
- **SCADA-уровень** — сбор телеметрии 1 Гц, многоуровневая мнемосхема с динамической
  индикацией, телеуправление (двухшаговый алгоритм), журналы ISA-18.2,
  осциллограммы при КЗ;
- **MES-уровень** — аналитика: временные ряды, гистограммы, карты Шухарта/CUSUM,
  экспорт CSV/Excel.

**Модель объекта** — учебная понизительная подстанция 110/10 кВ
(по MVP_SCADA_Denis.docx): два ввода 110 кВ → два трансформатора (T1/T2) →
две секции шин 10 кВ (по 4 фидера: Насосная, Вентиляция, Освещение, Резерв /
Станочный цех, Компрессорная…) → секционный выключатель (нормально отключён).
**Ключевой сценарий**: потеря ввода 110 кВ → переброс питания секции
через секционный QF (с блокировкой параллельной работы вводов).

«Оборудование» — Modbus TCP симулятор (2 устройства, unit 1/2) со сценарным
движком: КЗ, перегрузка, перенапряжение, обрыв кабеля, потеря ввода 110 кВ.
Замена на реальное оборудование = смена конфигурации адаптера (специф §13),
код выше адаптера не меняется.

## Запуск с нуля (~10 минут)

### 1. Установить (один раз)
- Python 3.12+ — https://python.org
- uv: `powershell -c "irm https://astral.sh/uv/install.ps1 | iex"`
- Node.js LTS 18+ — https://nodejs.org (для сборки UI)

### 2. Собрать и запустить
```bash
# Бэкенд: зависимости + БД создаются автоматически при первом старте
cd backend
uv sync
uv run uvicorn titan.api.app:app --host 127.0.0.1 --port 8000

# Фронтенд: собрать один раз (статика отдаётся FastAPI)
cd ../frontend
npm install && npm run build
```
Открыть **http://127.0.0.1:8000** — вход admin / admin (сменить в разделе
«Администрирование»!).

### 2а. База данных
- **PostgreSQL 16** (установлен локально, служба `postgresql-x64-16`,
  данные в `C:\PostgreSQL\data`).
- БД `titan` и пользователь `titan_app` / `titan2026` создаются вручную один раз:
  ```sql
  CREATE DATABASE titan ENCODING 'UTF8';
  CREATE USER titan_app WITH PASSWORD 'titan2026';
  GRANT ALL PRIVILEGES ON DATABASE titan TO titan_app;
  ```
- Таблицы создаются автоматически при старте приложения.
- Старые данные (SQLite `titan.db`) не переносятся автоматически —
  MVP начинался с чистой базы.

### 3. Проверка
```bash
cd backend && uv run pytest    # 47 тестов, все зелёные
```

## Демонстрация аварий (пульт симулятора, admin)
Кнопки в разделе «Пульт симулятора»:
- **КЗ (МТЗ)** — ток ×6, сработка защиты, отключение, осциллограмма в журнале
- **Перегрузка** — выход P и THDi за техно-границы (оранжевые ⚠️)
- **Перенапряжение** — U 460 В → suspect
- **Отказ привода** — команда ТУ не исполняется (неопределённое состояние)
- **Потеря связи** — все точки suspect (неопределённое состояние)

## Резервное копирование
```bash
cd backend
uv run python -m titan.backup_cli            # копия + ротация (хранить 7)
uv run python -m titan.backup_cli --list     # список копий
uv run python -m titan.backup_cli --restore titan_YYYYMMDD_HHMMSS.db
```
Ночной бэкап и автозапуск — через Task Scheduler или NSSM: см. **docs/DEPLOY.md**.

## Технические заметки
- **pymodbus закреплён на 3.9.2** — 3.12+ переделал API (ModbusSlaveContext →
  ModbusDeviceContext, SimData/SimDevice); обновление потребует переписать симулятор.
- Сервер pymodbus смещает адреса на +1 (`getValues: address += 1`) — движок пишет
  в datastore по адресу `addr + 1`.
- `AsyncModbusTcpClient` требует работающего event loop — коллектор создаётся в lifespan.
- SQLite в WAL-режиме + busy_timeout 30 с: коллектор и API пишут одновременно.
- Тесты изолированы: `TITAN_TEST_DB=1` (tests/conftest.py) — временная БД на процесс,
  рабочая titan.db не трогается; состояние симулятора сбрасывается после каждого теста.
- Обесточивание (BREAKER=0) — не авария: нулевые U/I/P/Q помечаются good
  (штатный режим после сработки защиты, а не потеря напряжения).
  ВАЖНО: если порт 5020 занят старым экземпляром сервера, новый тест/запуск
  подключится к старому состоянию — при «странных» значениях проверять
  netstat -ano | findstr :5020 и убивать зависший процесс.
- SPA-catch-all объявлен ПОСЛЕ всех /api/* маршрутов — иначе перехватывает их.
