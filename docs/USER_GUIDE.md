# Руководство пользователя
## ПАК «Титан-Энергия» (EMS) — учебная ПС 110/10 кВ

Руководство описывает работу с системой через браузер: что где смотреть,
как выполнять операции диспетчера и как демонстрировать сценарии аварий.

> Модель объекта: понизительная подстанция 110/10 кВ с двумя вводами
> 110 кВ, двумя трансформаторами (T1, T2), двумя секциями шин 10 кВ
> (по 4 фидера) и секционным выключателем (нормально отключён).
> Ключевой сценарий: авария на одном вводе → переброс питания через СВ.

---

## 1. Запуск и вход

**Запуск** (окно терминала должно оставаться открытым, пока работаешь):
```
cd C:\Users\HP\HermesProjects\titan-energy\backend
uv run uvicorn titan.api.app:app --host 127.0.0.1 --port 8000
```
Дождись строки `Application startup complete`.

**Вход:** открой в браузере `http://127.0.0.1:8000`.
На экране входа введи логин и пароль:
- администратор: **admin / admin** (по умолчанию)
- диспетчер / наблюдатель: учётки создаёт администратор (см. раздел 6)

После входа слева — панель навигации. Пункты зависят от роли:
| Пункт | Кто видит |
|---|---|
| Мнемосхема, Журналы, Аналитика | все роли |
| Администрирование, Пульт симулятора | только admin |

Внизу панели — твоя учётка и кнопка «Выйти».

**Роли** (права проверяются на сервере для каждого действия):
| Роль | Что может |
|---|---|
| viewer | только смотреть (схема, графики, журналы без кнопок) |
| dispatcher | + квитирование алармов, телеуправление, экспорт |
| admin | + пользователи, пульт симулятора, аудит входов |

## 2. Мнемосхема (главный экран)

Мнемосхема — **трёхуровневая**. Навигация — хлебные крошки сверху:
`ПС 110/10 → Секция I, 10 кВ → Ф-2`.

### Уровень 0 — обзор ПС (первый экран)
Плитки элементов подстанции: Плечо А, Плечо Б, Секция I, Секция II —
со статусом (● В работе / ○ Обесточено / ⚡ АВАРИЯ), мощностью и напряжением.
Отдельная плитка «Секционный QF» с состоянием и пояснением, зачем он нужен.
Ниже — тепловая карта аварий за час (цвет плитки фидера от зелёного к красному).
**ЛКМ по плитке** — перейти на уровень 1. **ПКМ** (admin) — создать аварию на объекте.

### Уровень 1 — однолинейная схема секции
Схема выбранного плеча/секции: ввод → трансформатор → вводной выключатель →
шина → 4 фидера с токами и названиями потребителей (Насосная, Вентиляция…).
**ЛКМ по объекту** — детали (уровень 2). **ПКМ по выключателю** — телеуправление.

При аварии на схеме появляется баннер: **человеческим языком + подсказка
«Что делать»** (например: «Потеря ввода 110 кВ → перебросьте питание,
включите секционный QF»). Подсказка не мигает — мигание только там,
где нужна реакция оператора.

Под схемой — **легенда цветов** (что значит каждый цвет/линия).

### Уровень 2 — детали объекта
Схема объекта (кабель → выключатель → нагрузка) + плитки показателей:
U, I, P, Q, THDu, THDi, PF. Оранжевая плитка с ⚠️ = выход за границы.

### Как читать индикацию (легенда)
**Кабельные линии:**
| Вид | Значение |
|---|---|
| сплошная тёмно-серая | под напряжением, норма |
| пунктирная блёкло-серая | обесточена |
| мигающий ярко-красный | аварийный режим |

**Коммутационные аппараты (квадраты):**
| Вид | Значение |
|---|---|
| заполненный зелёный квадрат | включён |
| пустой квадрат | отключён |
| квадрат с буквой «Р» | местное управление |
| оранжевый квадрат | неопределённое состояние |
| мигающий красный квадрат | авария (мигает до квитирования) |

Данные на схеме обновляются раз в секунду автоматически.

## 3. Секционный переброс (ключевой сценарий ПС)

На реальной ПС два ввода нужны для надёжности: при аварии на одной линии
питание перебрасывают на другую через секционный выключатель.

**Сценарий демонстрации:**
1. Пульт симулятора → выбрать «Ввод 110 кВ №1» → сценарий
   **«Потеря ввода 110 кВ»** → плечо А обесточено, critical-аларм
   «Требуется переброс через секционный QF».
2. На мнемосхеме **ПКМ по «Секционный QF» → Включить** →
   секция I запитывается от плеча Б через СВ (на плитке: U≈228 В).
3. Обратно: ПКМ по СВ → Отключить — вернуть нормальную схему.

**Блокировки СВ** (система не даст сломать схему):
- нельзя включить СВ при двух работающих вводах (параллельная работа запрещена);
- нельзя включить СВ при двух обесточенных вводах (нечего перебрасывать);
- ТУ на СВ разрешено именно при аварии «потеря 110 кВ».

## 4. Аларм-бар и квитирование

Внизу **всех** экранов — лента сообщений об авариях.

**Как читать строку:**
- приоритет цветом: `critical` — красный жирный, `high` — оранжевый, `info` — серый;
- время события с точностью до миллисекунд;
- объект и описание человеческим языком («Потеря ввода 110 кВ —
  требуется переброс через секционный QF»);
- значение сработки и уставка («знач.: 147.0 / уставка: 400»).

**Порядок строк** (ISA-18.2): сверху — неквитированные по важности
(critical → high → info), под ними — квитированные (приглушённые).

**Квитирование:** кнопка **«Подтвердить»** в строке (dispatcher+) —
мигание прекращается, появляется «ack: имя_пользователя».

## 5. Журналы

Раздел «Журналы» — таблица с фильтром. Четыре журнала (как в ТЗ):
1. **Все события**
2. **Аварийные события** (alarm)
3. **Ненормальные режимы** (abnormal)
4. **Изменения состояний** (state)

**Клик по имени объекта** в строке аларма → мнемосхема раскрывает
уровень этого объекта (быстрый поиск места аварии).

## 6. Администрирование (только admin)

**Пользователи** — таблица учёток: сменить роль, деактивировать/активировать,
создать нового (логин + пароль от 4 символов + роль).
Система не даст админу деактивировать самого себя.

**Аудит входов** — отдельная таблица: кто, когда, успех/отказ
(неудачные — красной строкой). Все входы логируются автоматически.

**Журнал действий операторов** — ВСЕ действия: квитирования, ТУ, инъекции
сценариев, изменения учёток, включая неудачные попытки (ТЗ 3.3.2).

## 7. Телеуправление (двухшаговый алгоритм ТЗ)

Доступно ролям **dispatcher** и **admin**. Управляемые аппараты:
ввод 10 кВ №1, ввод 10 кВ №2, секционный QF.

1. На мнемосхеме **ПКМ по выключателю** → окно «Телеуправление».
2. Выбери **«Включить»** / «Отключить». При блокировке увидишь красное
   сообщение с причиной (например: «параллельная работа вводов запрещена»).
3. Подтверждение с **обратным отсчётом 10 с** — успей нажать «Выполнить».
4. Система ждёт изменения состояния до 5 с (у привода задержка ~2 с).
5. Результат: «Команда исполнена» или «не исполнена — состояние не изменилось»
   (так бывает при сценарии «отказ привода»).
6. **Все шаги**, включая неудачные, — в журнале действий оператора.

## 8. Пульт симулятора (только admin, учебная фича)

Выбери объект в дереве (или ПКМ прямо на схеме) → выбери шаблон аварии →
длительность ползунком (3–30 с).

| Шаблон | Что происходит | Что показать зрителю |
|---|---|---|
| КЗ (МТЗ) | ток ×6, защита отключает ввод | мигающий красный, critical-аларм, осциллограмма |
| Перегрузка | ток/мощность за границы | оранжевые ⚠️, high-алармы |
| Перенапряжение | U = 460 В | оранжевая плитка U |
| Обрыв кабеля | фидер отваливается | просадка мощности |
| **Потеря ввода 110 кВ** | всё плечо обесточено | critical + **переброс через СВ** (ключевой сценарий!) |

После истечения длительности оборудование само возвращается в норму.

## 9. Аналитика (MES-уровень)

**Панель «Выбор»:** показатель (P/I/U/THDi), период (5/15/30 мин),
усреднение (30 с–5 мин), CUSUM target.

**Плитки статистики** — Макс / Мин / Среднее / σ.

**Четыре графика:**
1. **Временной ряд** — сырые значения + скользящее среднее. Зум мышью.
2. **Карта Шухарта** — CL/UCL/LCL; красная точка = процесс вне контроля.
3. **Гистограмма** — распределение, мода, медиана, σ, 3σ.
4. **CUSUM** — накопленное отклонение (растёт → дрейф параметра).

**Экспорт** — «Скачать CSV» / «Скачать Excel».

По умолчанию графики строятся по вводу №1 (плечо А). Можно выбрать
конкретный объект: код точки вида `arm1_incomer:P`, `sec1_f2:I`.

## 10. Типовой сценарий демонстрации (5–7 минут)

1. **Мнемосхема (уровень 0)** — «обзор подстанции 110/10: два плеча,
   две секции, секционный выключатель, данные раз в секунду».
2. **Открыть плечо** (ЛКМ) — «однолинейная схема секции, фидеры с токами».
3. **Пульт → Потеря ввода 110 кВ** (плечо А) — «плечо обесточено,
   критический аларм с подсказкой: включите секционный QF».
4. **Переброс**: ПКМ по Секционному QF → Включить — «секция запитана
   от соседнего плеча — так обеспечивается надёжность».
5. **КЗ на фидере** — «сработка МТЗ, мигание, осциллограмма, аларм с уставкой».
6. **Квитирование в аларм-баре** — «мигание прекратилось, в журнале
   кто и когда подтвердил».
7. **Аналитика** — Шухарт, гистограмма, CUSUM → «Скачать Excel».
8. **Админка** — «аудит входов: кто и когда входил, неудачные попытки —
   красным; полный журнал действий».

## 11. Частые вопросы

**Данные не обновляются / всё оранжевое** — у симулятора сценарий
«потеря связи» или сервер перезапускается. Подожди 10 с.

**«Телеуправление запрещено»** — активная авария (кроме потери 110 кВ,
при которой переброс разрешён). Дождись окончания сценария.

**«Параллельная работа вводов запрещена»** — пытался включить СВ при двух
работающих вводах. Так и задумано: переброс делается только когда одно
плечо обесточено.

**Не пускает под admin/admin** — пароль сменили или БД пересоздана.

**Где хранятся данные** — PostgreSQL (база `titan`, подключение в `.env`).
Бэкапы — `backend/backups/`.

**Как перезапустить** — Ctrl+C в терминале, затем команда из раздела 1.
**Сброс к заводским** — пересоздать базу `titan` в PostgreSQL.
